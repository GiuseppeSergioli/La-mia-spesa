COME AGGIORNARE IL SITO GIÀ PUBBLICATO
1. Estrai lo ZIP e apri la cartella spesina.
2. Su GitHub apri GiuseppeSergioli/La-mia-spesa, ramo main.
3. Add file > Upload files: trascina i file e le cartelle CONTENUTI in spesina, mantenendo le sottocartelle. package.json deve rimanere nella radice del repository. Carica i file estratti, non lo ZIP e non un ulteriore livello spesina/. Sono necessari anche il nuovo server/local-stores.mjs e il public/demo.mjs ampliato.
4. Conferma il commit. Attendi il nuovo deploy automatico del servizio Render esistente; se disabilitato usa Manual Deploy > Deploy latest commit.
5. Riapri la tua URL Render. /api/status deve indicare versione 1.2.0 e radius.max uguale a 6. configuredStores resterà 0 finché non vengono configurati veri feed prezzi.
6. Prova la demo, aggiungi un prodotto, premi Torna alla home e poi Riprendi la demo: il prodotto deve essere ancora in lista. Con Prova una lista pronta puoi esplorare quattro esempi.
7. Per i negozi reali prova Parti dal centro di Cagliari. Anche se la mappa non risponde, vedrai le voci locali comprese nel raggio. Con 3 km dal centro non vedrai tutti gli 8 punti dell’elenco, perché alcuni sono più lontani.
8. Se la versione è corretta ma la pagina sembra vecchia, ricarica forzando l’aggiornamento del browser.

Non serve cambiare le autorizzazioni GitHub o creare un nuovo servizio Render. Questo pacchetto aggiorna soltanto La-mia-spesa e non cambia le altre applicazioni. La URL del sito esistente rimane la stessa. La chat non ha caricato o distribuito automaticamente questo aggiornamento.

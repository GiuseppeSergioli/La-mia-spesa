LA MIA SPESA — AGGIORNAMENTO 1.6.0

COSA DEVE APPARIRE NELLA HOME
Un grande pulsante verde Componi la tua spesa, con simbolo del carrello.
Sotto, un piccolo comando Cerca supermercati, indicato come facoltativo e informativo.
Componi la tua spesa apre subito i prodotti: non occorre prima cercare o scegliere un supermercato.
La ricerca dei negozi continua mentre compili il carrello. Una risposta lenta o un errore della mappa non chiude la pagina prodotti.

VERIFICA DI AVER AGGIORNATO LA VERSIONE GIUSTA
In fondo alla home deve comparire v1.6.0.
Nel server, /api/status deve restituire version 1.6.0.
La demo autonoma dist/index.html mostra la home aggiornata e permette di comporre la spesa senza Internet.

AGGIORNARE GITHUB E RENDER
1. Estrai La-mia-spesa-1.6.0.zip.
2. Nella cartella estratta trovi direttamente package.json, package-lock.json, public, server, dist e gli altri file.
3. Apri GiuseppeSergioli/La-mia-spesa su GitHub, nella pagina principale del repository.
4. Add file > Upload files: carica i file e le cartelle estratti, mantenendo le sottocartelle. package.json deve stare alla radice; public e server devono sostituire le cartelle esistenti.
5. Conferma Commit changes. Se compare un errore, riapri package.json dal repository e verifica se la versione è arrivata; il messaggio esatto serve per capire l’eventuale blocco.
6. Su Render, nel servizio esistente: Manual Deploy > Deploy latest commit.
7. Riapri l’app e controlla il pulsante Componi la tua spesa e v1.6.0 in fondo. Se necessario, sul Mac aggiorna con Cmd+Shift+R.

La URL resta quella già usata. Questa chat non ha eseguito il deploy.
